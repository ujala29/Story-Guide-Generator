# extractor.py — Stage 1 Orchestrator

## Purpose
The single orchestrator that runs the full Stage 1 extraction pipeline in the correct order. This is the **only file** that needs to be called from outside Stage 1. All other files in `Extraction/` are internal implementation details called from here.

---

## Input / Output

| | Detail |
|---|---|
| **Input** | `semantic_model_path` — path to `.SemanticModel` folder |
| **Input** | `report_path` — path to `.Report` folder |
| **Input** | `output_path` — where to write `extracted_schema.json` |
| **Output** | `extracted_schema.json` — full extraction in one JSON file |
| **Output** | `schema_sections/` folder — one JSON file per section |
| **Output** | `schema_sections/measures_resolved.json` — full DAX chain per measure |

---

## Pipeline Order (must not be reordered)

```
Step 1  TMDLExtractor          → tables, measures (raw), relationships
Step 2  MeasureDependencyGraph → enrich measures with depends_on / depth / is_leaf
Step 3  build_visual_map()     → shared visual lookup dict (built ONCE, reused in Steps 4 & 5)
Step 4  ReportLayoutParser     → pages, visuals, filters, interactions
Step 5  BookmarkExtractor      → bookmarks, toggle groups
Step 6  ReportMetaParser       → theme, report settings, custom visuals
Step 7  ExtractionSummary      → aggregate counts
Step 8  ExtractedSchema        → assemble all results + write JSON
```

---

## Function Flow

```
run_extraction(semantic_model_path, report_path, output_path)
  │
  ├── Step 1: TMDLExtractor(semantic_model_path)
  │     ├── .extract_tables()          → tables[]
  │     ├── .extract_all_measures()    → all_measures[]
  │     └── .extract_relationships()   → relationships[]
  │
  ├── Step 2: MeasureDependencyGraph(all_measures)
  │     ├── .enrich_measures()         → all_measures[] (mutated in place)
  │     ├── .build_edges()             → edges[]
  │     └── .topological_order()       → topo_order[]
  │     └── .build_summary()           → dep_summary{}
  │
  ├── Step 3: build_visual_map(pages_dir)
  │     └── → visual_map{}             (reused in steps 4 & 5)
  │
  ├── Step 4: ReportLayoutParser(report_path)
  │     └── .extract(visual_map)       → pages[], visuals[], filters[], interactions{}
  │
  ├── Step 5: BookmarkExtractor(report_path)
  │     └── .extract(visual_map)       → bookmarks[], toggle_groups[]
  │
  ├── Step 6: ReportMetaParser(report_path)
  │     └── .extract()                 → report_meta{}
  │
  ├── Step 7: Build ExtractionSummary(counts + dep_summary)
  │
  ├── Step 8: Build ExtractedSchema(all fields)
  │     ├── .model_dump_json() → write extracted_schema.json
  │     └── _write_section_files() → write schema_sections/
  │
  └── return schema
```

---

## Function Details

### `run_extraction(semantic_model_path, report_path, output_path)`
Main pipeline function. Calls all parsers in order and assembles results. Returns `ExtractedSchema` and also writes it to disk.

### `_write_section_files(schema, output_path)`
Saves each top-level field of `ExtractedSchema` as a separate JSON file inside `schema_sections/`. Also calls `resolve_all()` (from `measure_resolver_.py`) to generate `measures_resolved.json`.

**Files written by `_write_section_files`:**
```
schema_sections/
  summary.json
  tables.json
  measures.json
  relationships.json
  pages.json
  visuals.json
  filters.json
  bookmarks.json
  dependency_graph.json
  measures_resolved.json    ← generated by measure_resolver_.py
```

## Hardcoded Parts (Change for New Dashboards)

> **Dashboard configs in `__main__` block** (lines ~240–270): The `_DASHBOARD_CONFIGS` dict inside the `if __name__ == "__main__"` block has hardcoded paths for `risk-dash` and `pac-dash`. If running `extractor.py` **directly** (not via `runner.py`), you must add new dashboards here.

```python
_DASHBOARD_CONFIGS = {
    "risk-dash": {
        "semantic_model": _BASE_DIR / "input" / "Risk-Management-v4_Insights_v1.SemanticModel",
        "report":         _BASE_DIR / "input" / "Risk-Management-v4_Insights_v1.Report",
        "output":         ...
    },
    "pac-dash": { ... },
    # ADD NEW DASHBOARD HERE
}
```

> **When running via `runner.py`** (the normal path), dashboard configs come from `utils/config.py` — no changes needed here.
