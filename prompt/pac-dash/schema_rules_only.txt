━━━ DATE FILTER RULES — apply exactly as written ━━━

  RULE A — BASE measures (no time-intel suffix):

    PAC_TABLE
        WHERE DATE_TRUNC('month', PAC_VISIT_START_DATE) = :selected_month

    INPATIENT_PAC_V4_VIEW
        WHERE MONTH_OF_VISIT = :selected_month

    PCP_VISITS_VIEW
        WHERE MONTH_OF_ATTRIBUTION = :selected_month

    PCP_VISITS_V4_VIEW
        WHERE MONTH_OF_DATE = :selected_month

    !! NONE of the PAC tables have MAX_MONTH_FLAG — never add it !!

  RULE B — TIME-INTEL measures (PY, PM, YoY, MoM):

    PY — prior year (SAMEPERIODLASTYEAR):
        PAC_TABLE             : WHERE DATE_TRUNC('month', PAC_VISIT_START_DATE) = DATEADD(year,  -1, :selected_month)
        INPATIENT_PAC_V4_VIEW : WHERE MONTH_OF_VISIT        = DATEADD(year,  -1, :selected_month)
        PCP_VISITS_VIEW       : WHERE MONTH_OF_ATTRIBUTION  = DATEADD(year,  -1, :selected_month)
        PCP_VISITS_V4_VIEW    : WHERE MONTH_OF_DATE         = DATEADD(year,  -1, :selected_month)

    PM — prior month (PREVIOUSMONTH):
        PAC_TABLE             : WHERE DATE_TRUNC('month', PAC_VISIT_START_DATE) = DATEADD(month, -1, :selected_month)
        INPATIENT_PAC_V4_VIEW : WHERE MONTH_OF_VISIT        = DATEADD(month, -1, :selected_month)
        PCP_VISITS_VIEW       : WHERE MONTH_OF_ATTRIBUTION  = DATEADD(month, -1, :selected_month)
        PCP_VISITS_V4_VIEW    : WHERE MONTH_OF_DATE         = DATEADD(month, -1, :selected_month)

    YoY ratio = (current - prior) / prior:
        current subquery → base date filter with :selected_month
        prior   subquery → base date filter with DATEADD(year,  -1, :selected_month)

    MoM ratio = (current - prior) / prior:
        current subquery → base date filter with :selected_month
        prior   subquery → base date filter with DATEADD(month, -1, :selected_month)

    !! NO MAX_MONTH_FLAG anywhere in any PAC time-intel subquery !!

  RULE C — CONTEXT_REMOVER (ALL / ALL('DATE')):
    No date filter whatsoever — omit WHERE clause entirely.

━━━ SQL CONVENTIONS ━━━

  - DIVIDE(a, b)    → a / NULLIF(b, 0)
  - DIVIDE(a, b, 0) → COALESCE(a / NULLIF(b, 0), 0)
  - Always use SELECT ... FROM ... (no CTEs unless strictly necessary)
  - Never use DATE_TRUNC on INPATIENT_PAC_V4_VIEW or PCP_VISITS_VIEW —
    those tables have pre-computed month columns
  - Never add MAX_MONTH_FLAG to any PAC table — that column does not exist
